# Academic Portfolio

A professional academic portfolio and professional homepage designed for faculty members and researchers to showcase their academic career, research publications, teaching experience, and achievements.

## Overview

This project serves as a comprehensive digital presence for academics. It is built to present information clearly and elegantly, highlighting essential aspects of an academic career. The platform includes dedicated sections for educational background, research focus, publications, patents, taught courses, and guided students. 

An integrated administrative dashboard is also provided to allow for seamless content management without requiring direct code modifications.

## Features

*   **Comprehensive Academic Profile**: Structured presentation of education, current position, and professional trajectory.
*   **Research and Publications**: Dedicated sections for research overviews, detailed publication lists, and registered patents.
*   **Teaching and Mentorship**: Archives of courses taught and records of students guided at undergraduate and postgraduate levels.
*   **Administrative Dashboard**: Secure backend interface for managing and updating portfolio content dynamically.
*   **Responsive Design**: Optimized for viewing across desktop, tablet, and mobile devices.

## Technology Stack

*   **Framework**: Next.js (React)
*   **Styling**: Tailwind CSS for utility-first responsive design
*   **Language**: TypeScript for static typing and enhanced code reliability

## Local Development Setup

To run this project locally on your machine, follow these steps:

1.  Ensure you have Node.js installed.
2.  Install the required dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm run dev
    ```
4.  Open `http://localhost:3000` in your web browser to view the application.

## Deployment

This application is configured for seamless deployment on Vercel. 

1.  Connect your GitHub repository to Vercel.
2.  Import the project.
3.  Vercel will automatically detect the Next.js framework and handle the build process.
